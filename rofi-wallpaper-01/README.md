# Rofi Wallpaper 01 — Vora
Execute `bash launch.sh`. Exibe miniaturas em uma grade e aplica automaticamente a imagem selecionada com `awww img` ao confirmar com Enter ou clique.
Inicia `awww-daemon` se necessário e encerra o swaybg anterior da sessão Vora após aplicar a imagem.
Origem: ~/Imagens/wallpapers, incluindo subpastas. Requer Python 3, Rofi, awww e awww-daemon.
